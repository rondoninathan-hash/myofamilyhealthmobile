# MyoFamily Health — Mobile Website

A simple, phone-sized website for MyoFamily Health.

## Pages / Sections
- **Home** – Hero with call-to-action
- **Services** – Six health services (cards)
- **About** – Mission statement + stats
- **Contact** – Contact info + appointment request form

## Files
| File | Purpose |
|---|---|
| `index.html` | Single-page HTML |
| `style.css` | Mobile-first styles |
| `app.js` | Bottom-nav active state + form feedback |
